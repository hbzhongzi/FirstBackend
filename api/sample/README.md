# sample 小程序接口文档

`sample` 是当前注册的小程序 `programKey`，业务名称为“今天要做什么饭”。本目录只保存该小程序的前端接口、后端落地、SQL 和原型资料。

## 文档目录

- [前端接口文档](./今天要做什么饭-前端接口文档.md)：请求封装、页面接口映射和联调规则。
- [后端接口落地说明](./今天要做什么饭-后端接口落地说明.md)：业务模块、接口规则和实现边界。
- [SQL 落地文档](./今天要做什么饭-SQL落地文档.md)：业务表、字段注释、索引和 seed 数据。
- [原型示例](./今天要做什么饭-示例.html)：交互参考，不作为服务端数据契约。
- [开发更新文档](../../doce/今天要做什么饭开发更新说明.md)：代码落地、测试和发布状态。
