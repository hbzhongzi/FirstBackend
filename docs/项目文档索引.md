## 阅读顺序

### 前端开发

1. 阅读对应小程序目录下的[前端接口文档](../api/sample/今天要做什么饭-前端接口文档.md)。
2. 按[API 文档入口](../api/README.md)确认公共登录和文件接口。
3. 联调时使用响应中的 `request_id` 定位后端日志。

### 后端开发

1. 阅读[项目开发规范](./项目开发规范.md)和[目录结构说明](../doce/目录结构说明.md)。
2. 阅读业务后端落地说明和 SQL 文档。
3. 修改代码、路由、迁移后同步更新接口文档和开发更新说明。

### 部署维护

1. 按[项目初始化部署文档](./项目初始化部署文档.md)配置环境和数据库。
2. 执行迁移、导入 seed，并验证 `/api/sample/v1/health`。
3. 检查固定图片目录权限、按小程序分区日志和生产安全配置。

## 文档维护规则

- 新增接口必须同时更新路由、代码、接口文档和联调示例。
- 已执行的 migration 不修改原文件，结构变更新增带时间序列的 migration。
- 文档示例不得写入真实 AppSecret、Token、手机号或用户隐私。
- 发现文档与代码不一致时，先以当前代码行为为准，再补齐文档和测试。
